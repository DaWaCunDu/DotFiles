* OS Specific Configs:

:PROPERTIES:
:CUSTOM_ID: os-specific-configs
:END:

This file is shared by both machines: the Mac mini =FONTAWA= darwin, the
Pi =FONTAWA= linux-nt. Anything that must differ between them belongs in THIS
section and nowhere else.

Keep it one section with =FONTAWA= cond= branches per OS, rather than a "macOS"
heading and a "Linux" heading side by side. Two headings means two copies of the
same fact, and keeping them in sync by hand is exactly how the per-machine
config files drifted apart in the first place.

As of the last edit, =doom-font= is the only thing that differs. Everything else
-- the modeline clock, vterm popup width, =fill-column=, and the org emphasis
faces -- is deliberately identical on both, so that stays out of here.

#+begin_src emacs-lisp
;; >>> ArchGodot/OpenCode: ADDED (OS Specific Configs section) -- search "OpenCode" to revert
;; The Pi runs Emacs in a terminal, so it needs a bigger font than the Mac's GUI
;; frame. This is the ONLY per-OS setting; if 16 turns out to be wrong on the
;; Pi, it is the one number to change.
(cond
 ((eq system-type 'linux-nt)
  (setq doom-font (font-spec :family "JetBrains Mono" :size 16)))
 ((eq system-type 'darwin)
  (setq doom-font (font-spec :family "JetBrains Mono" :size 14))))
;; <<< ArchGodot/OpenCode: END
#+end_src

;; >>> ArchGodot/OpenCode: ADDED (org emphasis color) -- search "OpenCode" to remove
;; Org puts *bold* and /italic/ emphasis on the plain `bold' and `italic' faces.
;; doom-old-hope renders those as bright white, which is nearly unreadable next
;; to normal text. Markdown-mode instead colors emphasis orange via its own
;; `font-lock-emphasis-face'. These two faces point org at the SAME face, so
;; org emphasis matches markdown exactly and keeps tracking your theme.
;;
;; Deliberately NOT changed: emphasis markers stay hidden (org-hide-emphasis-markers
;; untouched), =verbatim=, ~code~, +strike+ and _underline_ are all as they were.
;; Nothing else in org is affected.
;;
;; To revert: delete everything between these two marker lines.
;; If `font-lock-emphasis-face' ever stops resolving (e.g. markdown-mode removed
;; from init.el), swap the :inherit for a literal color instead:
;;   :foreground "#e0a05f"
;; Attribute values below are deliberately UNQUOTED. In a defface spec a bare
;; symbol is the literal attribute value, while a quoted one (:weight 'bold) is
;; an error: "Wrong type argument: symbolp, 'bold". Verified against Emacs 30.1.
(defface org-emphasis-bold
  '((t :inherit font-lock-emphasis-face :weight bold))
  "Org *bold* emphasis, colored like markdown-mode emphasis.")
(defface org-emphasis-italic
  '((t :inherit font-lock-emphasis-face :slant italic))
  "Org /italic/ emphasis, colored like markdown-mode emphasis.")
(setq org-emphasis-alist
      '(("*" org-emphasis-bold)
        ("/" org-emphasis-italic)
        ("_" underline)
        ("=" org-verbatim verbatim)
        ("~" org-code verbatim)
        ("+" (:strike-through t))))
;; <<< ArchGodot/OpenCode: END
